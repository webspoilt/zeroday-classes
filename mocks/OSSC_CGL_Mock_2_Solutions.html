1. Arithmetic - 10th Standard (Q.1-25)
Q.1: Money doubles in 8 yrs SI. 4 times? Option C (24 years)
Interest for doubling = P. To become 4P, total interest needed = 3P. Time = 8 * 3 = 24 years.
Q.2: 20% discount, 20% profit, CP ₹1200. MP? Option B (₹1800)
SP = 1200 * 1.2 = 1440. MP = 1440 / 0.8 = ₹1800.
Q.3: A(15d), B(20d), 6 days together. B alone? Option A (6 days)
Together rate 7/60. In 6 days 42/60 = 7/10. Remaining 3/10. B takes (3/10) * 20 = 6 days.
Q.4: Price +32%, Exp +10%. Consumption change? Option D (27.5 kg)
33 * 1.1 / 1.32 = 27.5 kg.
Q.5: Avg speed 40 km/h and +50% speed back. Option C (48 km/h)
Avg = 2*40*60 / (40+60) = 48.
Q.6: Downstream speed boat 15, stream 3. In 12 mins? Option B (3.6 km)
Speed = 18. Dist = 18 * (12/60) = 3.6 km.
Q.7: 54 km/h train crosses platform 30s. Train 150m. Option C (300m)
Speed = 15 m/s. Dist = 450m. Platform = 450-150 = 300.
Q.8: ₹10k part 8%, part 10%. Int ₹920. Option C (₹4k)
0.08x + 0.1(10k-x) = 920 -> 0.02x = 80 -> x = 4000.
Q.9: CI ₹8k for 1.5 yrs @ 10% half-yearly. Option B (₹1261)
8000(1.05)^3 - 8000 = 1261.25.
Q.10: Amount ₹4624 (2yrs), ₹4913 (3yrs) CI. Rate? Option A (6.25%)
Rate = (289/4624)*100 = 6.25%.
Q.11: Boat 6 km/h, Stream 2. Round trip 3 hrs. Option B (8 km)
d/8 + d/4 = 3 -> 3d/8 = 3 -> d = 8.
Q.12: Avg +1.5kg for 8 men when 65kg replaced. Option D (77 kg)
65 + (8 * 1.5) = 77.
Q.13: Largest no divides 1305, 4665, 6905 same remainder. Option B (1120)
HCF of diffs (3360, 2240) = 1120.
Q.14: Amount ₹1331 for 3 yrs @ 10% CI. P? Option A (₹1000)
1331 / (1.1)^3 = 1000.
Q.15: (5x-2y):(7x+2y) if x:y=3:4. Option C (7:29)
(15-8)/(21+8) = 7/29.
Q.16: 12km in 45m. Speed +4 km/h. New time? Option B (36 min)
Current = 16. New = 20. 12/20 * 60 = 36.
Q.17: X(24d), Y joins after 4. Finish 16 total. Y? Option D (36 days)
X works 16d. Y works 12d. Y rate = 1/3 in 12d -> 36d.
Q.18: Base +20%, Height -20%. Area change? Option A (4% decrease)
1.2 * 0.8 = 0.96.
Q.19: Fill 12h, Leak makes 15h. Leak alone? Option C (60 hours)
1/12 - 1/15 = 1/60.
Q.20: Product 2028, HCF 13. Pairs? Option B (2)
ab = 2028/169 = 12. Pairs (1,12),(3,4).
Q.21: A(80d). After 10d, B finish 42d. Together? Option A (30 days)
B rate = 7/8 in 42d -> B=48. Together = 1/30.
Q.22: ₹1600 SI ₹252 in 2.25 yrs. Rate? Option B (7%)
252 / (16 * 2.25) = 7.
Q.23: A(20), B(30), C(60). Assisted every 3rd day. Option C (15 days)
3 days work = 1/20 + 1/20 + 1/10 = 1/5. Total = 15.
Q.24: Buy 6 for ₹1, Sell to gain 20%. Option D (5)
CP of 1 = 1/6. SP = 1.2/6 = 1/5. So 5 for a rupee.
Q.25: Length +60%. Width dec to keep area? Option A (37.5%)
60/160 * 100 = 37.5.
